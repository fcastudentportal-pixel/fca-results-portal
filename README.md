First Class Academy (FCA) Results Portal
A modern web-based student results portal for First Class Academy (FCA). The system allows students and parents to access academic results using a student number and access password.
🌐 Live Website
FCA Results Portal:
https://fcastudentportal-pixel.github.io/fca-results-portal/
📌 About the Project
The FCA Results Portal was created to provide students and parents with a simple and convenient way to view academic results online.
The website uses the FCA school branding, including a maroon and gold color scheme, and provides a clean results page suitable for viewing and printing.
✨ Features
🎓 Student results lookup
🔎 Search using student details
📊 Display of academic results
🧾 Printable results page
📄 A4-friendly results layout
📱 Responsive design for phones and computers
🏫 First Class Academy branding
🔐 Admin dashboard for managing school information
👨‍🎓 Student management
🏫 Class management
📚 Results management

Students
Classes
Academic results
Student numbers

🖨️ Printing Results
The results page is designed to display properly on an A4 page when printed.
The print layout removes unnecessary website elements and focuses on the student's official results.
